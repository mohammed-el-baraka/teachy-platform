## 🌍 Multi-Language Support (i18n)

The platform supports dynamic language switching across 4 languages with complete localization and RTL text rendering:
- 🇺🇸 **English** (EN)
- 🇫🇷 **Français** (FR)
- 🇲🇦 **العربية** (AR - with full Right-to-Left RTL support)
- 🇪🇸 **Español** (ES)

## 🚀 Features & Pages

1. **Landing / Home Page** (`#/`):
   - Hero: "Join Our Online Language Courses" with yellow squiggle underline, pink "Register Now" pill, and instant demo contact line `0666774426`.
   - Visual student showcase with animated floating live tutor status.
   - Interactive Course Directory with filter pills (All, English, Spanish, French, German, Chinese, Arabic).
   - "How Teachy Works" 3-step immersion method.
   - Native Tutors showcase with audio preview.
   - Interactive Fluency check quiz.
   - Social proof metrics (+10,000 learners, +500 tutors, 98% fluency rate).

2. **Sign Up Page** (`#/signup`):
   - Client-side validation, full-width purple/pink buttons, and instant redirection to live classroom.

3. **Login Page** (`#/login`):
   - 1-Click "Demo Login" button with prefilled credentials.

4. **Course / Live Session Page** (`#/course`):
   - Interactive virtual classroom with simulated video call, microphone/camera controls, live AI transcription subtitles, real-time feedback, and agenda notes.

5. **My Path Page** (`#/mypath`):
   - CEFR proficiency roadmap (A1 to C2), speaking streak counter, hours practiced, and speaking skill breakdown.

6. **Session History Page** (`#/history`):
   - Past completed 1-on-1 sessions, tutor feedback reports, pronunciation accuracy scores, and lesson takeaway notes.

7. **About Page** (`#/about`):
   - Vision & mission, engineering background by Mohammed El Baraka, and UM6P / EMINES context.
